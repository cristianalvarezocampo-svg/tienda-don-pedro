# 🛒 Tienda Don Pedro

Proyecto para la administración de la tienda de Don Pedro. Sirve para mostrar sus productos, llevar el registro de clientes y ventas, y calcular el valor del inventario.

## Productos

| Producto | Precio |
|----------|--------|
| Arroz 1kg | $4.500 |
| Leche 1L | $4.500 |

## Estructura

```
tienda-don-pedro/
├── datos/
│   ├── clientes.txt
│   ├── productos.txt
│   └── ventas.txt
├── src/
│   └── main.py
├── .gitignore
└── README.md
```

## Cómo ejecutarlo

```bash
python src/main.py
```
